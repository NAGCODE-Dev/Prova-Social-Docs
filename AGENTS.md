# Instruções para agentes

## Objetivo

Este repositório contém a documentação técnica e estratégica do Prova Social.

## Regras

- Leia a documentação relevante antes de alterar uma decisão existente.
- Preserve a estrutura e os links internos do Obsidian.
- Use Markdown simples e legível.
- Não remova decisões anteriores sem registrar a mudança.
- Quando uma decisão arquitetural mudar, registre o motivo em `03 - Decisões/`.
- Não trate esta documentação como substituta do código-fonte.
- O código do aplicativo permanece no repositório principal do Prova Social.

## Princípio

O Prova Social deve fazer o mínimo de processamento necessário para produzir o máximo de confiança possível.
